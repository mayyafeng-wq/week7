# Enable Graphite Diamond on `mayyafeng-wq/week7`

Diamond does **not** run from the CLI. It runs on Graphite’s servers after you enable it for the repo.

## Steps

1. Sign in: https://app.graphite.dev/
2. Install the **Graphite GitHub App** on account `mayyafeng-wq` (Settings → GitHub authentication → Install app).
3. Open **Diamond / AI code review** settings (see https://graphite.com/docs/ai-reviews-setup).
4. Enable Diamond for repository **`mayyafeng-wq/week7`** and save.
5. Open each PR in Graphite (or GitHub). Diamond analyzes new/updated PRs automatically; you can also use **Re-run** in the PR sidebar if available.
6. Confirm review comments appear on:
   - https://github.com/mayyafeng-wq/week7/pull/1
   - https://github.com/mayyafeng-wq/week7/pull/2
   - https://github.com/mayyafeng-wq/week7/pull/3
   - https://github.com/mayyafeng-wq/week7/pull/4
7. Copy Diamond summaries into `week7/writeup.md` section **c** for each task.
